One fortune-cookie line for a software engineer, written to
`/output/entry.txt` by a small TypeScript program. The line:

> You will fix the bug on Friday; it will return on Monday wearing a different error message.

## Run

```sh
node main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
